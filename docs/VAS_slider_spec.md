## 1. 概要・目的

本仕様書は、iPhone 15 Pro Max 上で視覚的アナログスケール（VAS）を 0–100 mm 実長に近い形で再現し、バイアスの少ない主観的疼痛評価を行うための設計仕様を示す。
対象は線維筋痛症ステージ IV–V の患者であり、操作負荷を最小限に抑えた単純な入力動作（画面のどこでもタッチして左右にスライド）を前提とする。
測定結果は研究用途（例: 疼痛評価研究、介入効果の検証など）での利用を想定し、再現性と透明性を重視する。
また、別途収集される環境データ（例: 5分毎の気圧・室温・湿度ログ）と紐付けて解析できるよう、VAS 測定時刻を高精度に保存する。

## 2. 測定フロー仕様

詳細: [UI仕様](#ui仕様), [実装詳細](#実装詳細)

1. **患者ID登録**
   - 初回起動時、被験者は患者ID（例: 「001 山田たか」）を入力する。
   - 登録された患者IDは、以降のVAS記録と紐付けて保存される。
   - 患者IDは検者メニューから確認・リセットできる。

2. **初期状態**  
   - アプリ起動時、患者IDが登録済みであれば、VAS 三角形バーとガイドが中央付近（約50）に配置された状態で表示される。
   - デフォルトではノンバイアスモード（絵文字・説明文なし）とし、三角定規バーと青い縦棒のみが表示される。

3. **表示モード切り替え**
   - 画面右上の歯車アイコンをタップすると検者用メニューが開き、「標準モード」と「ノンバイアスモード」を切り替えられる。
   - 標準モードでは、バーの左右に絵文字（😀／😫）と「全く痛くない／耐えられないほど痛い」の説明文を表示し、患者への説明やデモに用いる。
   - ノンバイアスモードでは、三角定規バーと縦棒のみを表示し、視覚的・言語的バイアスを低減した本測定用画面とする。

4. **調整フェーズ（adjusting）**
   - 対象者は画面上の任意の位置をタッチし、そのまま左右にスライドさせることで、三角バー上の青い縦棒を左右（VAS 0–100 に対応）に移動させる。
   - この段階では数値（0–100）などのフィードバックは一切表示しない。

5. **記録フェーズ（valueShown）**
   - 対象者が「記録」ボタンをタップすると、その時点の縦棒の位置をVAS値として一時的に確定する。
   - 画面中央下部付近に VAS 値（整数 0–100）が一度だけ大きく表示され、約10秒間保持される。

6. **最終確定・保存**
   - 値表示中、アプリは内部でVAS値を CSV ファイルに保存する。
   - 保存される項目は「タイムスタンプ（秒単位）・患者ID・VAS値・表示モード」であり、必要に応じて環境データと後から突き合わせ可能とする。
   - 保存完了後、VAS 値の表示は自動的に消え、縦棒は中央付近（50 付近）にリセットされる。

7. **再測定**
   - 原則として、対象者の任意判断による直後の「やり直し」は行わない。
   - 研究上必要な場合のみ、検者が検者用メニューや再測定操作を通じて、測定を再実施する。

## 3. UI仕様

詳細: [測定フロー仕様](#測定フロー仕様), [実装詳細](#実装詳細)

### 3.1 画面構成

- 上部:  
  - タイトル（例: 「現在の痛みの強さ」）  
  - 必要最小限の説明文（患者向け案内）
  - 右上に歯車アイコン（検者用メニュー／表示モード切替・患者ID確認）

- 中央:  
  - VAS 三角形バー（斜面）  
  - その上に重ねるスライド可能なガイド

- 下部:  
  - 「記録」ボタン（患者用）

### 3.2 三角形バー（斜面）

- 紙製 VAS スケールの三角定規を模した形状とし、底辺が 0–100 mm に対応する。  
- 左端を 0、右端を 100 とみなし、右へ行くほど痛みが強い方向性を表現する。  
- バーは単色もしくは緩やかなグラデーションのみとし、目盛線や区切り線は表示しない（バイアス低減のため）。

### 3.3 ガイド（縦バー）

- 三角形バー上に重ねる細長い縦長の矩形とし、「現在の位置」が視覚的に分かる最小限の強調（色）を付与する。
- ガイドは画面上の任意位置をタッチし、左右にドラッグする操作によってのみ移動し、バー領域の外には出ないよう制限する。

### 3.4 情報表示

- 調整フェーズでは、VAS 値（0–100）・目盛り・数値ラベルは表示しない。
- 「記録」ボタンタップ後のみ、画面中央付近に VAS 値（整数 0–100）を一時的に表示する。
- 検者向けの情報（表示モード、現在の患者ID、CSVエクスポートなど）は、歯車アイコンから開く検者用メニュー内にまとめて表示し、対象者の注意を引かない位置とデザインとする。
- 標準モードでは、三角形バーの左右に絵文字（😀／😫）と「全く痛くない／耐えられないほど痛い」の説明文を表示し、説明・デモ用とする。ノンバイアスモードではこれらを非表示とし、三角形バーとガイドのみを表示する。

## 4. 実装詳細

詳細: [測定フロー仕様](#測定フロー仕様), [UI仕様](#ui仕様)

### 4.1 物理長さの扱い

- `PhysicalMetricsConverter` などを用いて、iPhone 上で **100 mm に相当するポイント長** を算出し、これを `vasWidth` として使用する。[7]
- 三角形バーの `frame(width: vasWidth, height: vasHeight)` を設定し、デバイス差を吸収する。

### 4.2 三角形バーの描画

- SwiftUI の `Shape` を用いて `TriangularVASBar` を定義する。  
- `path(in rect: CGRect)` 内で、  
  - 左下: \((rect.minX, rect.maxY)\)  
  - 右下: \((rect.maxX, rect.maxY)\)  
  - 上側の任意点（例: \((rect.minX, rect.minY)\)）  
  の 3 点を結んだ三角形を描画する。

### 4.3 ガイドとカスタムスライダー

- ガイド位置は `@State var value: Double`（範囲 0–100）として保持する。  
- 三角形バーを背景とし、その上に `ZStack` でガイドを重ね、`DragGesture` または `Gesture` 合成により、  
  - ドラッグ位置（x 座標） ↔ `value`（0–100）の変換を行う。[12]
- 実装クラス（例）  
  - `struct VASSliderView: View`  
    - プロパティ: `@Binding var value: Double`  
    - プロパティ: `let vasWidth: CGFloat`  
    - 内容: `TriangularVASBar`＋ガイド＋ドラッグ処理

### 4.4 測定フェーズ管理

-測定状態はブール値で管理する。
  - isShowingValue: Bool：VAS値を一時的に表示するかどうか。
  - isRecording: Bool：記録処理中かどうか。
- 「記録」ボタンタップ時に isRecording = true, isShowingValue = true とし、一定時間（例: 10秒）経過後にデータ保存処理を行い、isRecording = false, isShowingValue = false とする。

### 4.5 記録とリセット

- 保存時に、以下の項目を1行のレコードとして CSV 形式で端末内に追記する。
  - タイムスタンプ（例: yyyy-MM-dd HH:mm:ss、秒単位）
  - 患者ID（例: 「001 山田たか」）
  - VAS値（0–100 の整数）
  - 表示モード（Standard / NonBiased）
-必要に応じて、環境センサー側の 5分毎ログ（気圧・室温・湿度など）との突き合わせができるように、時刻情報を揃えて記録する。
- 記録処理完了後、vasValue を 50 付近にリセットし、ガイドを中央付近に戻す。
